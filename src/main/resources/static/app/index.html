Quick Help

This simple UI lets you manage Batches and Interns.

  • Create a batch first, note its Batch ID.
  • When creating an intern, enter that Batch ID in the Batch ID field.
  • Use the Edit and Delete buttons in the tables to modify or remove records.
  • Open the H2 console at /h2-console (JDBC URL: jdbc:h2:mem:testdb, user: sa).
